# SpellRankUp

[English](../README.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Português](pt-BR.md) · [Italiano](it.md) · [Русский](ru.md) · [한국어](ko.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md)

Neuen Rang eines Zaubers gelernt? SpellRankUp legt ihn sofort auf deine Aktionsleisten – auf jeden Platz, auf dem der alte Rang lag.

Für **WoW Forever**, in der Sprache deines Spiels.

## So funktioniert es

- Lernst du einen höheren Rang (Stufenaufstieg oder Lehrer), bekommt jeder Aktionsplatz mit einem niedrigeren Rang desselben Zaubers den neuen Rang.
- Wie beim Lernen eines neuen Zaubers: Das Symbol erscheint am Lehrer (oder in der Bildschirmmitte), fliegt zum Knopf und lässt ihn aufleuchten.
- Sonst wird nichts angefasst: andere Zauber, Makros und Gegenstände bleiben, wo sie sind. Einen absichtlich niedrigen Rang lässt es liegen, solange du keinen neuen Rang dieses Zaubers lernst.
- Im Kampf werden die Plätze direkt nach dem Kampf aktualisiert.

## Befehle

`/spellrankup on` · `/spellrankup off` · `/spellrankup` (Status) · `/spellrankup anim` (Animation an/aus) – kurz: `/sru`
