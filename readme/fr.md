# SpellRankUp

[English](../README.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Português](pt-BR.md) · [Italiano](it.md) · [Русский](ru.md) · [한국어](ko.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md)

Vous avez appris un nouveau rang d’un sort ? SpellRankUp le place aussitôt sur vos barres d’action – sur chaque bouton où se trouvait l’ancien rang.

Pour **WoW Forever**, dans la langue de votre client de jeu.

## Fonctionnement

- Quand vous apprenez un rang supérieur (montée de niveau ou maître), chaque bouton d’action portant un rang inférieur du même sort reçoit le nouveau rang.
- Comme quand on apprend un nouveau sort : l’icône apparaît chez le maître (ou au milieu de l’écran), vole jusqu’au bouton et le fait briller.
- Rien d’autre n’est modifié : les autres sorts, macros et objets restent en place. Un rang inférieur placé exprès reste tant que vous n’apprenez pas de nouveau rang de ce sort.
- En combat, les boutons sont mis à jour juste après le combat.

## Commandes

`/spellrankup on` · `/spellrankup off` · `/spellrankup` (état) · `/spellrankup anim` (animation oui/non) – en bref : `/sru`
