# SpellRankUp

[English](../README.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Português](pt-BR.md) · [Italiano](it.md) · [Русский](ru.md) · [한국어](ko.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md)

学会了法术的新等级？SpellRankUp 会立即把它放到动作条上——放在每个原来是旧等级的按钮上。

适用于 **WoW Forever**，使用你游戏客户端的语言。

## 工作方式

- 当你学会更高等级（升级或训练师）时，每个放着同一法术较低等级的动作按钮都会换成新等级。
- 其他内容一概不动：其他法术、宏和物品保持原位。你特意放置的低等级会一直保留，直到你学会该法术的新等级。
- 战斗中，按钮会在战斗结束后立即更新。

## 命令

`/spellrankup on` · `/spellrankup off` · `/spellrankup`（状态）– 简写：`/sru`
