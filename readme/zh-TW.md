# SpellRankUp

[English](../README.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Português](pt-BR.md) · [Italiano](it.md) · [Русский](ru.md) · [한국어](ko.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md)

學會了法術的新等級？SpellRankUp 會立即把它放到快捷列上——放在每個原本是舊等級的按鈕上。

適用於 **WoW Forever**，使用你遊戲用戶端的語言。

## 運作方式

- 當你學會更高等級（升級或訓練師）時，每個放著同一法術較低等級的快捷按鈕都會換成新等級。
- 其他內容一概不動：其他法術、巨集和物品保持原位。你刻意放置的低等級會一直保留，直到你學會該法術的新等級。
- 戰鬥中，按鈕會在戰鬥結束後立即更新。

## 指令

`/spellrankup on` · `/spellrankup off` · `/spellrankup`（狀態）– 簡寫：`/sru`
